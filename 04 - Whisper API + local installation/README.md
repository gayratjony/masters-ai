# 🎙 Whisper AI - Speech-to-Text Transcription App  

This **Streamlit-based web app** utilizes OpenAI's **Whisper model** to convert spoken audio into text with high accuracy.  

## 🚀 Features  
✅ **AI-powered transcription** using OpenAI’s Whisper model  
✅ **Instant text output** from audio files  
✅ **User-friendly web interface** built with Streamlit
