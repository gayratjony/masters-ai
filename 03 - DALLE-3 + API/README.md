# 🎨 AI-Powered Image Generator - Multiple Artistic Styles

This **Streamlit app** generates AI-powered images in various artistic styles using OpenAI's **DALL·E API**. Simply enter a prompt, and the app will create **9 unique images** in different styles.

## ✨ Features  
✅ Enter a **custom text prompt**  
✅ Generates **9 different images** per request  
✅ Uses OpenAI's **DALL·E** for AI-driven image creation  
✅ Automatically displays images with an option to save
